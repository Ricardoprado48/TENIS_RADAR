# 001 — OBJETIVO E ESCOPO

## Objetivo

Criar uma base estatística confiável para pesquisar mercados pré-jogo de tênis.

O sistema deverá futuramente produzir:

- projeções;
- distribuições probabilísticas;
- probabilidades por linha;
- odds justas;
- odds mínimas aceitáveis.

Antes disso, precisamos descobrir quais mercados são realmente previsíveis.

## Mercados iniciais

1. Aces por jogador
2. Total de aces
3. Total de games
4. Handicap de games
5. Double faults
6. Total de sets
7. Tie-break

## Fora do escopo atual

- interface web;
- aplicativo;
- Supabase;
- integração com casas;
- apostas automáticas;
- scraping contínuo de odds;
- monetização.

## Regra central

Toda previsão deve considerar a interação entre os jogadores.

Serve A × Return B

Serve B × Return A

## Critério de sucesso da primeira etapa

Ao final da pesquisa devemos conseguir responder:

"Quais mercados conseguimos prever com menor erro usando dados públicos disponíveis antes da partida?"
